## 1. 快速上手（3 分钟跑通第一个任务）

1. **登录**：浏览器访问系统，使用管理员分配的账号（默认演示账号 admin/admin123）
2. **进入研发工作台**（首页 → 研发工作台，或直接点「从一句话开始」）
3. **输入研发目标**——例如：`开发冲击强度 ≥ 8 kJ/m² 的玻纤增强 PA6 改性料`
4. **点击「智能解析」**：系统自动识别体系 PA6 + 冲击强度约束，点击「应用到表单」
5. **点击「生成计划」→「确认执行」**：AI 自动生成候选配方并估算性能
6. **查看候选**：左侧候选列表（性能/评分/可信度徽标）→ 右侧详情
7. **送下游**：发送实验 / 发送配方 / 送工艺深化

> 不想打字？点击目标框下方的**场景模板**（PA6 玻纤增强/PC 阻燃/ABS 增韧…）一键填充。

## 2. 角色与权限

| 角色 | 主要能力 |
|---|---|
| 研究员 | 研发目标、候选生成/筛选、实验执行、数据录入 |
| 项目经理 | 项目创建、AI 任务拆解、审批（实验任务/放行卡/QC） |
| 实验员 | 实验任务执行、样品/设备管理、数据录入 |
| 系统管理员 | 用户/权限/系统设置、领域包切换、审计 |
| 访客 | 只读查看公开项目 |

菜单按角色自动收敛（研究员默认只见研发链页面），管理/能力库页面需对应权限。

## 3. 分角色操作指南

### 3.1 研究员

**研发目标 → 候选 → 实验**：
1. 研发工作台输入目标并解析（见快速上手）
2. 候选列表：按综合评分/拉伸强度/弯曲模量等排序；勾选加入对比（雷达图/对比表）
3. 候选详情：查看性能估算（注意"工程估算"徽标，关键决策前需实验实测）、放行卡状态
4. 发送实验：创建实验任务单（候选估算值自动作为预期值，供后续偏差分析）
5. 实验闭环迭代（ECML）：设置目标体系/属性 → 运行 → 查看「闭环验证精度」

**候选状态机**：初筛 → 可行性 → 工艺规划 → 工艺确认 → 可实验（任意环节可拒绝）

### 3.2 项目经理

1. **创建项目**：项目名称 + 一句话目标（智能目标框解析）→ AI 拆解任务
2. **审批**：我的待办（审批/QC 审批/放行卡），放行卡「同意」后候选解锁可下单
3. **看板**：首页项目进度、预算使用、风险预警

### 3.3 实验员

1. **实验工作台**：查看待执行任务单 → 录入结果（选择标准方法模板：GB/T 1040 拉伸等）
2. **数据质量**：查看 QC 判定（规则可解释）
3. **偏差分析**：录入完成后对比预期值（候选估算）vs 实测，标记异常
4. **样品/设备**：样品批次管理、设备台账与校准

### 3.4 系统管理员

1. **系统设置**：研发领域（默认改性塑料 kingfa）、运行模式（演示/生产，切换立即生效）、LLM 配置
2. **用户与角色**：创建用户、分配权限
3. **主数据治理**：属性/单位/分类/检测方法（新增需先入 MDM 表）
4. **审计日志**：全操作审计（防篡改）

## 4. 数据可信度怎么看

系统每个数值旁有**徽标**：
- 🟢 **实测**：真实实验测量（已过数据质量审批）——可信最高
- 🟠 **模拟**：系统仿真值（演示模式）——不进入学习，仅供流程演示
- 🔵 **模型预测**：带真实权重的模型产出
- ⚪ **工程估算**：基于骨架查表的量级估计——**未经实验验证，关键决策需实测确认**

鼠标悬停徽标可看详细说明。实验数据的来源列同样展示该徽标。

## 5. 常见问题

**Q：为什么候选性能显示"工程估算"？**
A：候选配方属性来自工程塑料数据库查表（CAMPUS/GB-T 参考区间），是量级估算而非实测。系统承诺诚实标注，正式决策前请通过实验闭环实测验证。

**Q：演示模式和生产模式有什么区别？**
A：演示模式（demo）下实验闭环自动生成模拟测量值（围绕估算值±10%，明确标"模拟"）；生产模式（production）下实验任务等待真实数据录入，审批门禁完整生效。

**Q：点击"发送实验"提示需要放行卡审批？**
A：高置信度不足或检索未验证的候选会自动生成放行卡（我的待办 → 放行卡）。审批"同意"后即可下单；这是 AI 研发的审计门禁。

**Q：为什么 ECML 显示 MAPE 8.8%？**
A：这是"闭环验证精度"——本轮估算值与实验（模拟或实测）的平均相对偏差。演示模式下模拟值围绕估算值±10%生成，所以偏差通常较小；生产模式显示真实精度。

**Q：找不到某个菜单？**
A：菜单按角色收敛。如确需使用，请联系管理员调整角色权限（或系统设置 → 导航可见性）。

**Q：导入 Excel 提示某行数值无效被跳过？**
A：该行"数值"列不是合法数字。请检查原文件（保留表头、数值列不要带单位文字），修正后重新导入。
