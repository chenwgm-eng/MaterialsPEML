# ADR-0003: 综合评分采用绝对规格基准

- **状态**: 已接受（2026-08-11）
- **背景**: 综合评分此前在"当前候选池"内 min-max 归一化：同一候选在不同列表分数不同、跨 run 不可比；单条候选恒为 0 分；补算（等权 4 属性）与生成器（配置权重）口径不一致。评分语义是"池内排名"而非"绝对质量"。
- **决策**:
  1. 评分基准改为**绝对规格范围**（按属性预置：拉伸 0-200 MPa、弯曲 0-20000 MPa、冲击 0-60 kJ/m²、HDT 0-300 °C，来源附在参考表中，领域包可覆盖）。
  2. 生成器加权评分与后端补算统一使用同一基准表与同一权重口径（领域包权重，默认等权）。
  3. 属性超出规格范围时钳制到边界；无基准的属性回退池内相对并显式标注"相对评分"。
- **备选**: 保持池内相对并标注（被否：跨 run 不可比是硬伤）；绝对基准但权重仍分裂（被否：口径不一致让分数不可解释）。
- **后果**: 分数跨列表/跨轮次可比，可作为"离规格多近"的度量；ECML 收敛判定与综合评分解耦（阈值表独立演进）。
