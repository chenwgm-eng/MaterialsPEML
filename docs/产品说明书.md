## 1. 产品定位

MaterialsPEML Lab 是面向**高分子改性塑料研发**的 AI 辅助平台。研发人员从"一句话研发目标"开始（例如"开发冲击强度 ≥ 8 kJ/m² 的玻纤增强 PA6 改性料"），系统自动完成：

**材料体系识别 → 候选配方生成 → 性能估算 → 工业化验证 → 实验闭环 → 反馈迭代**

核心价值：
- **研发提效**：AI 生成候选配方（基材 × 增强/阻燃/增韧组合），估算性能并附来源
- **数据可信**：每一条数据带可信度标签（实测/模拟/模型预测/工程估算），模拟数据绝不冒充实测
- **闭环可审计**：估算 → 实验 → 偏差分析（MAPE）全链路可追溯
- **零门槛上手**：智能目标框输入一句话即开始，场景模板一键填充

## 3. 功能模块全景

### 3.1 研发核心
- **研发工作台**：一句话目标 → 智能解析（体系/属性自动回填）→ AI 生成研发计划 → 执行并实时查看进度
- **材料设计**：候选材料工作台（生成/筛选/对比/评分/送下游），含临时预测模式
- **实验闭环迭代（ECML）**：7 步闭环（生成→工业化→估算→验证→实验→反馈），带验证精度指标
- **配方与工艺**：BOM/BOP 配方设计（基材+增强+助剂）、成本与合规评估
- **合成路径**：逆合成路线规划（ASKCOS/本地模板，回退透明）+ 工艺深化

### 3.2 实验与数据
- **实验工作台**：任务单创建/审批/执行/数据录入（GB-T 标准方法模板）
- **实验数据**：查询/编辑/导入（CSV/Excel）/偏差分析（估算 vs 实测）
- **数据质量**：QC 规则（可解释）+ 学习池门控
- **样品与批次**、**设备与校准**、**数据接入**（字段映射）

### 3.3 知识资产
- **技术情报**：文献检索与摄入
- **知识库**：材料-主张-证据（双维可信度）
- **知识图谱**：关系可视化
- **物料规格库**：企业物料主数据（分类 FK 受控）
- **属性字典 / 主数据治理**：MDM 统一管理

### 3.4 能力与管理
- **智能体与工具**：多智能体编排、工具注册、SCP 集成、能力契约
- **放行卡中心**：审批门（防死锁自动补卡）
- **我的待办**：审批/QC/放行卡聚合入口
- **管理看板/预算/收益/用户/审计/设置**：企业治理

## 4. 核心能力详解

### 4.1 智能目标框（学习成本 ≈ 0）
在研发工作台/项目创建/智能编排输入一句话目标：
- 自动识别材料体系（PA6/PC/ABS/PP…，词边界匹配防误判）
- 自动解析性能约束（"冲击强度 ≥ 8 kJ/m²" → 属性+阈值）
- 场景模板一键填充（PA6 玻纤增强/PC 阻燃/ABS 增韧/PP 汽车件/PBAT 降解）

### 4.2 工程塑料候选生成（查表法）
- 22 种基材骨架（PP/PA6/PC/ABS/PBT/PPS/PEEK…）× 增强方案（玻纤/碳纤/滑石粉/阻燃/增韧）
- 性能来自 CAMPUS 数据库 + GB-T 参考区间查表（带来源标注），**无派生系数**
- 绝对规格基准综合评分（0-100%，跨 run 可比）

### 4.3 实验闭环与验证精度
- ECML 7 步闭环自动迭代（目标达标判定用领域包阈值）
- **闭环验证精度**：每轮反馈展示估算 vs 实测 MAPE、±10% 命中率（demo 模式对比模拟实测，生产模式对比真实实测）
- 偏差分析：候选估算值自动带入订单预期值，一键对比

### 4.4 数据可信度审计链
四档徽标（实测绿/模拟橙/模型预测蓝/工程估算灰）贯穿候选列表/详情/实验数据：
- 模拟数据落库即标 simulated + 不进入学习池
- 每条实验记录带 provenance（来源/证据等级）
- 工程估算带来源标注（GB-T/CAMPUS）

## 5. 数据可信度体系

| 档位 | 含义 | 何时出现 |
|---|---|---|
| 实测 | 真实实验测量，已过 QC 审批 | 实验数据（verified） |
| 模拟 | 系统仿真值（demo 模式） | 实验闭环演示 |
| 模型预测 | 带真实权重的模型（Tg/介电常数） | 聚合物性质预测（罕见） |
| 工程估算 | 查表/启发式量级估计 | 候选配方属性（最常见） |

> 术语承诺：系统从不把估算伪装成预测，从不把模拟伪装成实测。
