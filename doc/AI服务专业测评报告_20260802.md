### 7.3 适配器调用模式

所有 Docker 引擎遵循统一适配器模式（[execution_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/execution_adapter.py)）：

1. **生成输入文件**：在临时工作目录生成引擎所需的输入（SMILES→PDB、packmol.inp、in.lammps、PySCF Python 脚本）
2. **Docker 执行**：`docker run --rm -v <workdir>:/work <image> <cmd>`，挂载工作目录，容器内执行后输出 JSON/PDB/log 文件
3. **解析输出**：适配器读取输出文件，结构化为标准 Artifact 返回
4. **回退策略**：Docker 不可用时回退到 RDKit 经验近似（ESP/MD）或返回明确降级标记

关键适配器文件：
- [pyscf_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/pyscf_adapter.py)：PySCF ESP（Mulliken 电荷 + vdw 表面采样）与轨道分析
- [formulation_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/formulation_adapter.py)：packmol 分子堆积（PDB 格式、Unix 行尾、shell 重定向）
- [lammps_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/lammps_adapter.py)：LAMMPS MD + log.lammps 热力学解析 + dump 轨迹分析
