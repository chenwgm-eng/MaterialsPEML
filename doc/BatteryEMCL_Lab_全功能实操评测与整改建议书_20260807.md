## 1. 执行摘要

- **当前成熟度：受控试点（不可正式交付）**。证据：左侧导航与页面骨架完整，Agent→工具→能力契约三层治理可见，主数据/物料/样品/设备/属性字典等企业级 LIMS 雏形已具备；但存在两项阻断性 P0——电池寿命预测页整页 404、晶体候选生成违反元素严格子集硬约束。此外材料路由无法识别化学式、预测结果缺失溯源与项目/任务关联、配方 BOM 与目标材料跨体系错配、ECML 因无实验数据无法启动，均导致"AI 驱动研发闭环"无法作为可信决策工具。
- **值得保留的实现与原因**：
  1. **Agent/工具/能力契约治理链**：拓扑页、映射控制台、能力契约、控制平面完整呈现 Activity → Agent → Tool → Capability 四层绑定，工具白名单/风险等级/降级链/SLA 可见。
  2. **主数据体系**：物料规格库、属性字典、MDM 分类树、设备台账、样品状态字段完整，单位/合规/供应商字段齐备，具备企业级数据治理基础。
  3. **详情抽屉交互范式**：配方 BOM/BOP/EHS、材料 3D 结构、知识图谱 canvas 渲染统一，符合用户"统一交互范式"偏好。
  4. **数据质量 QC 流程说明页**：初筛 → 人工复核 → 拒绝回路 → 归档学习四阶段明确。
- **最重要的 P0/P1 风险**：
  - P0-1：`POST /discover/crystal` 输入 `Li6PS5Cl`（允许元素集合 Li/P/S/Cl），返回 `Li10GeP2S12`（含 Ge）、`Na3Zr2Si2PO12`（含 Na/Zr/Si）、`Li7La3Zr2O12`（含 La/Zr/O）、`Li3InCl6`（含 In）、`Na3PS4`（含 Na），全部违反 strict-subset 元素过滤硬约束，且 `prediction.predicted_value={}`、`provenance=[]`。
  - P0-2：`/battery-life` 前端路由返回 404，菜单入口为死链。
  - P1-1：`POST /route` 对 `Li6PS5Cl` 返回 `material_type:unknown`、`confidence:0.2`，无法按化学式识别材料类型。
  - P1-2：配方 `BOM-6B8FC3F20A` 目标材料为硫化物晶体 `Cl-rich LPSCl`，BOM 明细却为 `PEO + LiTFSI` 聚合物体系；配方列表页总成本显示 ¥0.00，但详情抽屉总成本显示 ¥1,814.80，列表与详情口径不一致。
  - P1-3：晶体/聚合物预测结果中 `project_id/task_id/scenario_id` 全空、`provenance=[]`、`predicted_value={}`，临时预测无法反查项目/任务。
  - P1-4：聚合物候选生成返回静态 known/rule_based 模板，confidence=null、molecular_weight=0.0，非真实预测。
- **整改策略：先治本、后治表**。先修复 P0 数据可信与死链，再补齐预测溯源与 ECML 数据闭环，最后做 UI/UX 收敛。
- **推荐整改顺序**：P0 晶体元素过滤 / 电池寿命死链 → P1 路由识别 / 配方一致性 / 预测溯源 / 聚合物静态模板 → P1 ECML 数据前置 → P2 控制平面健康探测 / 主数据清理 → P3 UI/UX 精修。

## 2. 测试方法、环境与局限

- **证据分级规则**：`[已实操验证]` = 完成真实浏览器/API 操作并获得可观察结果；`[高概率推断]` = 有 UI/接口/数据一致性迹象但未完成完整验证；`[待确认]` = 受权限、数据、外部服务或时间限制无法判断。高概率推断与待确认项不计入"已复现缺陷"统计。
- **环境、权限、外部服务与数据限制**：
  - 浏览器：Playwright Chromium headless，分辨率 1600×900。
  - 账号：系统管理员，全部项目可见；未测试研究员/审核员/只读访客等角色的权限边界。
  - 外部服务：控制平面显示 LLM/DFT/SCP 等服务健康状态全部为 `-`，未探测，无法确认真实外部调用可用性。
  - 数据：实验数据/数据质量当前为空；ECML 因"无实验数据"无法启动；委员会、Release Card 无待办。
- **未验证清单及最小补测条件**：
  1. ECML 完整七步闭环、委员会裁决、Release Card 审批实战 → 需先录入/导入 ≥1 条真实实验结果，并配置审批角色与项目任务。
  2. 真实外部 SCP 工具调用（PubChem/ChEMBL/浙大图谱/InternAgent 等）→ 需在系统设置中配置 AI4S/SCP 服务地址与密钥，并通过控制平面"自检"复现成功响应。
  3. 多角色权限矩阵（研究员/项目经理/审核员/访客）→ 需创建对应角色账号，逐页验证 403/功能可见性。
  4. 电池寿命预测后端实现 → 需确认后端是否存在 `/api/workflows/battery_life` 或替代服务。

## 4. 端到端研发闭环验证

### 4.1 材料发现到实验闭环（路由可通，候选生成存在致命可信缺陷）

- **操作步骤与关键对象**：
  1. `POST /api/route`，输入 `Li6PS5Cl` → 返回 `material_type:unknown`、`branch:crystal_branch`、`confidence:0.2`、`reason:无法判定材料类型：输入不含可识别的 PSMILES/SMILES/结构文件或材料类型关键词`（EV-API-ROUTE）。
  2. `POST /api/discover/crystal`，输入 `Li6PS5Cl`（元素集合 Li/P/S/Cl），目标属性离子电导率 → 返回 5 个候选：CAND-10759312 `Li10GeP2S12`、CAND-8D8D968A `Na3Zr2Si2PO12`、CAND-C4B007C4 `Li7La3Zr2O12`、CAND-117C77F3 `Li3InCl6`、CAND-691A8521 `Na3PS4`（EV-API-CRYSTAL）。
  3. `POST /api/discover/polymer` → 返回 10 个已知模板（PEO/PVDF/PMMA/PAN/PPC/PPO/PVA 等），`source:known/rule_based`、`confidence:null`、`molecular_weight:0.0`、`predicted_value:{}`（EV-API-POLYMER）。
- **成功节点**：后端接口 200、响应结构符合 schema、`ai_meta` 包含 model_version/confidence/generated_at、`degraded:false`。
- **失败节点**：
  - 路由对化学式无法识别（confidence 0.2）。
  - 晶体候选包含 Ge/Na/Zr/Si/La/In/O 等超出允许集合的元素，strict-subset 过滤未生效，`blocked_count:0`。
  - 候选的 `prediction.predicted_value={}`、`provenance=[]`、`project_id/task_id/scenario_id` 全空。
  - 聚合物候选为静态规则模板，无真实模型预测。
- **断点**：候选空间未按输入元素约束；预测结果未携带可解释的来源与项目/任务关联；无法从候选反查模型版本与输入快照。
- **逆向追溯**：临时调用未绑定项目/任务，返回对象缺少 `provenance` 与上下文 ID，无法完成"候选 → 模型版本 → 项目目标"追溯。
- **成熟度**：部分可跑通 / 不可信。
- **整改建议**：在 crystal 候选生成前强制按输入元素集合过滤；`predicted_value` 必须非空或明确降级；`provenance` 与项目/任务 ID 必须回填；polymer 分支若仅为模板应明确标注"规则模板/待模型验证"。

### 4.2 配方与工艺研发闭环（数据一致性存在硬伤）

- **操作步骤与关键对象**：进入 `/formula-design` → 打开 `BOM-6B8FC3F20A` 详情抽屉（EV-DEEP-001）。
- **成功节点**：抽屉展示 BOM/BOP/EHS 三栏，物料单价、库存、供应商字段完整，成本明细拆分可见。
- **失败节点**：
  - 目标材料：`Cl-rich LPSCl`（硫化物晶体体系）。
  - BOM 明细：`PEO + LiTFSI`（聚合物体系）。
  - 需求量字段为空（仅显示" kg"）。
  - 配方列表页该 BOM 总成本显示 `¥0.00`，但详情抽屉中物料成本 `¥158.00` + 加工成本 `¥1,656.80` = 总成本 `¥1,814.80`，列表与详情口径不一致。
- **断点**：目标材料与 BOM 跨体系错配；列表与详情成本汇总口径不一致；需求量未回填。
- **逆向追溯**：所有 BOM 在列表中均显示 `¥0.00`，无法从总成本反查物料单价×用量。
- **成熟度**：页面可用 / 数据不可信。
- **整改建议**：BOM 生成时校验目标材料体系与物料体系一致性；总成本按"物料+加工"汇总并明示口径；需求量必填/自动回填。

### 4.3 数据资产治理闭环（主数据完整，实时数据未闭环）

- **操作步骤**：
  1. 查看 `/properties` 属性字典、`/mdm` 主数据治理分类树、`/materials` 物料规格库、`/equipment` 设备台账、`/samples` 样品管理。
  2. 查看 `/data-ingest` 导入历史。
  3. 查看 `/data-quality`、`/experiments`。
- **成功节点**：属性字典字段模板、MDM 分类树、物料/设备/样品字段完整，单位与合规字段齐备。
- **失败节点**：
  - `/data-ingest` 7 条历史中有 5 条失败（`project` 实体 `review.csv` 连续失败）。
  - `/experiments`、`/data-quality` 均为 0 条，QC 待检队列为空。
  - `/samples` 42 条中混有 `SMP-001`、`LiCoO2-001`、`smp_Li6PS5Cl_2`、`Li6PS5Cl-样品-1-renamed` 等 demo/seed/测试数据。
- **断点**：导入失败未处理、实验数据未进入系统、真实数据与演示数据未隔离。
- **逆向追溯**：无实验结果可反向追溯至样品/批次/设备/原料/QC 规则。
- **成熟度**：主数据模型成熟 / 业务流程未闭环。
- **整改建议**：隔离/归档 demo 与 seed 数据；修复 data-ingest 失败根因；建立"实验结果 → QC → 归档学习"最小数据集。

## 8. UI/UX 重构规格

- **推荐左侧信息架构（按研发任务组织）**：
  - 我的研发：首页、我的待办、工作台（统一入口）。
  - 项目与目标：项目管理、研发工作台、收益账单。
  - 材料发现：材料设计、性质预测（临时/修复后）、合成路径、配方与工艺。
  - 实验与数据：实验工作台、实验数据、样品与批次、设备与校准、数据接入、数据质量。
  - 知识资产：技术情报、知识图谱、物料规格库、属性字典、主数据治理。
  - AI 与编排：智能编排、智能体管理、工具与连接器、映射控制台、能力契约、评估中心、控制平面。
  - 管理：管理看板、预算看板、用户与角色、系统设置。
  - **电池寿命入口在修复前隐藏**。
- **不同角色首页/工作台**：
  - 研究员：突出"继续上次工作"、"开始新材料研发"、"我的待办"。
  - 审核员：突出 QC 待审、Release Card 待复核、委员会 Case。
  - 管理员：管理看板 + 控制平面 + 预算/用户入口。
- **关键首屏、向导与渐进披露**：
  - `/ecml` 无数据时不应仅显示表单，应提供"录入实验数据"或"导入示例数据"向导。
  - `/prediction` 输入区与结果列表分离，空态仅出现在结果区。
  - `/formula-design` 列表页直接展示目标材料与体系徽标，便于发现错配。
- **空态、加载、失败、无权限、异步任务状态**：
  - 统一空态：图标 + 一句话说明 + 主按钮（下一步动作）。
  - 异步任务（AI 预测、ECML）显示阶段进度、预计耗时、队列位置、取消按钮。
  - 失败态展示错误原因、重试/反馈/联系管理员入口；禁止直接暴露接口字段名。
- **状态色、按钮层级、表格/筛选/批量/详情/版本对比规范**：
  - 状态色：成功=绿 `#52C41A`、警告=橙 `#FA8C16`、错误=红 `#F5222D`、信息=蓝 `#1890FF`、草稿=灰 `#8C8C8C`。
  - 主按钮使用橙色 `#FA8C16`，次按钮使用描边灰。
  - 表格首行固定筛选栏，分页与列设置统一；详情抽屉统一右滑，支持版本对比。
- **术语词表与必须替换文案**：
  - 统一"候选材料"（非"材料"）、"物料"（非"原料"）、"样品"（非"试样"）、"实验任务"（非"实验"）、"结果数据"（非"原始数据"）。
  - 禁止将 LLM 输出文案直接作为"安全"、"合规"、"可放行"结论；必须显示"AI 建议，需人工复核"。

## 9. 视觉设计系统建议

- **产品视觉定位**：黑-白-橙工业科技风，简洁紧凑，减少滚动，MiroFish 原生风格，AI 能力透明显示。
- **色板（Hex）**：
  - 主色橙：`#FA8C16`（强调、主按钮、选中态）
  - 深色背景：`#141414`（侧边栏/夜间模式）
  - 浅色背景：`#FFFFFF`（内容区）
  - 文字主色：`#262626`；次要文字：`#8C8C8C`；禁用：`#BFBFBF`
  - 边框/分割线：`#F0F0F0`
  - 成功：`#52C41A`；警告：`#FAAD14`；错误：`#F5222D`；信息：`#1890FF`
- **字体、字号、行高**：
  - 中文字体：系统默认无衬线（PingFang SC / Microsoft YaHei）
  - 标题：18-20px，行高 1.4；正文：14px，行高 1.6；辅助：12px，行高 1.5
  - 科学计数法使用上标（如 1×10⁻³），化学式自动下标（Li₆PS₅Cl）
- **间距、圆角、边框、阴影**：
  - 卡片内边距 16-20px；圆角 8px；边框 1px `#F0F0F0`；阴影 `0 2px 8px rgba(0,0,0,0.08)`
- **卡片/表格/图表/状态徽标**：
  - 卡片标题 16px 加粗，右上角状态徽标。
  - 表头 12px 灰色，行高 48px，hover 背景 `#FAFAFA`。
  - 状态徽标采用圆角标签，文字与背景对比度 ≥ 4.5:1。
- **化学式上下标、科学计数法、单位、精度规范**：
  - 化学式自动解析上下标；单位使用标准 SI（S/cm、eV、kg、g、mol 等）。
  - 科学计数法统一为 `a×10ⁿ`；数值保留 3 位有效数字或按业务规则。
- **禁止视觉模式**：
  - 禁止大面积渐变背景；禁止多色随机状态标签；禁止直接显示接口字段名或英文枚举值。

## 10. 数据模型、治理与 AI 可信度整改

- **核心对象关系与外键**：
  - 项目 → 目标/约束 → 候选（candidate） → 预测结果（prediction） → 合成路径 → 配方/BOM/BOP → 实验任务 → 样品/批次 → 原始数据 → 结果数据 → QC → ECML 学习 → Release Card → 收益账单。
  - 关键外键：`candidate.project_id`、`prediction.candidate_id`、`experiment.sample_id`、`experiment.equipment_id`、`bom.target_material_id`。
- **唯一标识、状态、版本、来源、审计字段**：
  - 所有业务对象必须包含 `id`、`created_at`、`updated_at`、`created_by`、`version`、`status`、`source`。
  - 样品/批次/设备/物料编码必须全局唯一；配方/BOM 版本不可变，复制新版本保留来源。
- **删除/修改保护、幂等与去重、统计口径、数据质量、血缘**：
  - 被引用的主数据禁止删除，仅可归档；删除需级联检查与审计日志。
  - Data Ingest 必须支持幂等键；失败行可修复重试。
  - 严格区分 `verified`（实测已审）与 `estimated`（预测/估算），禁止在统计与推荐中混算。
  - 建立从结果到原料/设备/样品/批次/预测/QC 规则的血缘链路。
- **AI/Agent 的输入快照、版本、证据、适用域、置信度、人工审核与放行机制**：
  - 每次 AI 调用记录 `input_snapshot`、`model_version`、`capability_id`、`tool_id`、`request_id`、`generated_at`。
  - 输出必须携带 `confidence`、`applicability`、`limitations`、`provenance`。
  - 低置信度、跨体系、未知材料类型、static template 必须触发 `human_review_required` 或 `release_card_required`，禁止自动放行到实验/合成/配方。
  - Capability Contract 中明确元素约束、适用域、风险等级、降级链、SLA；违规时由控制平面记录并告警。

## 11. 分阶段路线图

### 阶段 0：P0 止血与数据可信度（1-2 周）

- 目标：阻止无效 AI 结果被使用，修复死链。
- 范围：
  - 修复 `/discover/crystal` strict-subset 元素过滤；越界候选 blocked 并返回原因。
  - 修复 `/battery-life` 404（实现后端或隐藏入口）。
  - 修复配方 BOM 目标材料与明细体系一致性校验。
  - 修复配方总成本汇总逻辑。
- 明确不做项：UI 重设计、外部 SCP 接入。
- 前置依赖：元素解析库、化学式归一化服务可用。
- 验收指标：`Li6PS5Cl` 预测返回候选元素不越界；`/battery-life` 可访问或入口隐藏；配方详情总成本=分项之和。
- 风险：元素过滤规则可能误伤合法掺杂体系，需产品确认规则。
- 优先级：最高。

### 阶段 1：主研发链路可信（2-3 周）

- 目标：打通"材料发现 → 候选 → 预测 → 配方"主链路。
- 范围：
  - 提升 `/route` 对化学式/CIF/名称的识别置信度。
  - 预测接口回填 `predicted_value`、`provenance`、`project_id/task_id/scenario_id`。
  - 聚合物静态模板明确标注来源，禁止直接放行。
  - 临时预测结果可发送到项目/任务。
- 明确不做项：真实外部模型训练。
- 前置依赖：阶段 0 完成。
- 验收指标：`/route` 对 `Li6PS5Cl` confidence ≥ 0.7；预测结果带模型版本与来源；聚合物模板显示"规则模板"标签。
- 风险：模型版本/来源字段可能缺失历史数据，需迁移策略。
- 优先级：高。

### 阶段 2：LIMS/ELN 数据闭环与治理（3-4 周）

- 目标：建立最小实验数据闭环。
- 范围：
  - 修复 `/data-ingest` 失败根因，提供错误行修复/重试。
  - 隔离/归档 demo/seed 数据（样品、实验、物料、项目）。
  - 录入示例实验结果，验证 QC 自动触发与 ECML 启动。
  - 统一设备/物料/样品编码唯一性。
- 前置依赖：阶段 1 完成。
- 验收指标：可成功导入 1 条实验数据；QC 待检出现记录；ECML 可启动一轮。
- 优先级：高。

### 阶段 3：AI 可信度、委员会门禁与可观测性（3-4 周）

- 目标：AI 输出可解释、可审计、可控。
- 范围：
  - 全部 AI 输出统一 Capability Contract 与 Release Card 门禁。
  - 控制平面接入真实服务健康探测。
  - 委员会/Release Card 实战验证（创建 Case → 评分 → 裁决 → 放行）。
  - 知识图谱与候选/实验/项目联动。
- 前置依赖：阶段 2 完成。
- 验收指标：低置信度预测必须人工复核后才能下发实验；控制平面至少 3 个服务显示健康/异常状态。
- 优先级：中。

### 阶段 4：UI/UX 与视觉体系（2-3 周）

- 目标：统一交互范式，降低认知负荷。
- 范围：
  - 空态/加载/失败/异步状态统一。
  - 404 页保留导航；管理看板精简告警。
  - 化学式/单位/精度统一渲染。
  - 按角色优化首页/工作台。
- 前置依赖：阶段 0-1 完成。
- 验收指标：通过 UX 走查；空态文案不再与表单重叠；404 页与主站一致。
- 优先级：中。

### 阶段 5：试点与商业化交付（持续）

- 目标：在真实项目中验证三条端到端闭环。
- 范围：
  - 选择 1-2 个真实研发项目跑通"发现 → 实验 → QC → ECML → Release Card"。
  - 多角色权限矩阵实测。
  - 外部 SCP 工具接入与预算控制实战。
  - 收益账单与成本规则验证。
- 前置依赖：阶段 3 完成。
- 验收指标：完成 ≥3 条端到端闭环；P0/P1 缺陷清零 ≥2 周；外部 SCP 至少成功调用 1 次。
- 优先级：按试点节奏推进。

## 14. 最终交付判断

- **能否供真实新材料团队日常使用：否（仅可受控试点）**。在 P0 晶体元素过滤、电池寿命死链修复，并完成至少一条"材料发现 → 预测 → 配方/合成 → 实验 → QC → ECML"真实数据闭环验证前，不满足正式交付条件。
- **最优先的 10 项整改**：
  1. BEMCL-BATT-P0-001 电池寿命死链
  2. BEMCL-DISC-P0-001 晶体元素过滤
  3. BEMCL-ROUT-P1-001 材料路由识别
  4. BEMCL-FORM-P1-001 配方目标-BOM 体系一致性
  5. BEMCL-FORM-P1-002 配方列表与详情总成本口径不一致
  6. BEMCL-PRED-P1-001 预测溯源与 predicted_value
  7. BEMCL-POLY-P1-001 聚合物静态模板标注
  8. BEMCL-ECML-P1-001 ECML 数据前置与运行历史一致
  9. BEMCL-DATA-P1-001 数据接入失败处理
  10. BEMCL-SAMP-P2-001 demo/seed 数据隔离
- **应保留深化的功能**：
  - Agent→工具→能力契约→控制平面的四层治理链。
  - 映射控制台与调用关系拓扑。
  - 主数据治理、属性字典、物料规格库、设备台账。
  - 配方 BOM/BOP/EHS 详情抽屉。
  - 材料 3D 结构与知识图谱 canvas。
  - 数据质量 QC 四阶段流程页。
- **应合并、隐藏、降级或暂缓的功能**：
  - 电池寿命预测入口：隐藏直至后端实现。
  - 性质预测独立页：与"材料设计"工作台合并，避免重复入口。
  - 评估中心：当前为空，可作为阶段 3 的治理配套功能。
  - 跨尺度建模：若模型未就绪，应标注"实验中"并禁用主流程调用。
- **未满足哪些验收条件前，不得对外宣称"AI 驱动研发闭环"**：
  - 任意输入化学式 → 输出同体系候选且带模型版本/置信度/溯源。
  - ECML 至少完成一轮真实实验数据闭环并产生下一轮推荐。
  - 配方目标材料与 BOM 明细体系一致且成本汇总正确。
  - 所有 AI 输出在低置信度/规则模板/跨体系时经过 Release Card 或人工复核。
  - 外部服务健康状态可观测，控制平面不再全为 `-`。
