## 2. 各服务材料科学事实核查

### 2.1 MPA 分子性质预测（RDKit 描述符）

**测试化合物**：水、乙醇、苯、阿司匹林（4 种标准化合物）

| 化合物 | SMILES | MW（返回/文献） | logP（返回/文献） | HBA（返回/文献） | HBD（返回/文献） | 结论 |
|--------|--------|-----------------|-------------------|-------------------|-------------------|------|
| 水 | `O` | 18.015 / 18.015 | -0.825 / -0.65 | 1 / 1 | 2 / 2 | **PASS** |
| 乙醇 | `CCO` | 46.069 / 46.069 | -0.001 / -0.14 | 1 / 1 | 1 / 1 | **PASS** |
| 苯 | `c1ccccc1` | 78.114 / 78.114 | 1.687 / 2.03 | 0 / 0 | 0 / 0 | **PASS** |
| 阿司匹林 | `CC(=O)Oc1ccccc1C(=O)O` | 180.159 / 180.159 | 1.310 / 1.19 | 4 / 4 | 1 / 1 | **PASS** |

**材料科学家核查**：
- **MW**：4 种化合物分子量与 IUPAC 标准值完全吻合（精度 <0.01%）✓
- **HBA/HBD**：使用 Lipinski 定义（`CalcNumLipinskiHBA/HBD`），与药物化学惯例一致
  - 水：1 O → HBA=1 ✓；2 个 O-H → HBD=2 ✓
  - 阿司匹林：4 个 O 原子 → HBA=4 ✓（Lipinski 计数所有 N/O）；1 个羧基 O-H → HBD=1 ✓
- **logP**：RDKit 的 `MolLogP`（Crippen 算法）与实验值存在系统性偏差（~0.3-0.5 log unit），属算法差异而非错误，在 QSPR 模型容忍范围内

### 5.1 Docker 常驻容器改造（附加优化）

为提高执行效率并方便调试，本轮同步将 Docker 引擎从临时容器模式（`docker run --rm`）改造为常驻容器模式（`docker exec`）。

| 项目 | 临时模式（改造前） | 常驻模式（改造后） |
|------|--------------------|--------------------|
| 容器生命周期 | 每次调用启动+销毁 | `--restart unless-stopped` 长期运行 |
| 命令执行 | `docker run --rm` | `docker exec -w <workdir>` |
| 挂载策略 | 每次挂载 work_dir | 统一挂载 `_ENGINE_TMP_ROOT` 到 `/work`，按相对路径定位 |
| 调试便利 | 容器执行完即删除 | `docker exec -it <container> bash` 实时进入 |
| 启动开销 | 每次支付（秒级） | 仅首次支付 |

**改造涉及的适配器**：
- [docker_executor.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/docker_executor.py) — 统一常驻容器管理工具
- [lammps_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/lammps_adapter.py) — LAMMPS MD 引擎
- [formulation_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/formulation_adapter.py) — packmol 堆积引擎
- [pyscf_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/pyscf_adapter.py) — PySCF 量子化学引擎
- [vina_adapter.py](file:///d:/BattleFish/BatteryEMCL%20Lab/battery_materials_agent/infrastructure/executors/vina_adapter.py) — AutoDock Vina 对接引擎

**常驻容器列表**（运行后通过 `docker ps` 可见）：
