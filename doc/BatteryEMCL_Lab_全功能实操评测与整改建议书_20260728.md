## 1. 执行摘要

### 1.1 当前成熟度判断

**内部试用 / 受控试点之间，尚未达到可正式交付。**

判断依据：
- 后端 AI/Agent/SCP 核心能力基本可真实调用（16 项测试通过 15 项，仅 ECML 运行超时）。
- 浏览器端关键主数据链路仍存在阻断：设备台账因外键约束无法通过 UI 正常保存、数据接入导入按钮无响应、物料规格库列表因字段映射错误抛出 `toFixed` 异常。

### 1.2 值得保留的实现

1. **AI 输出可信度元数据**：候选生成、跨尺度分析、实验任务生成等接口均返回 `confidence`、`model`、`key_assumptions`、`evidence_sources`、`human_review_required` 等字段，符合材料研发可审计要求。
2. **幂等保护**：实验任务创建使用 `idempotency_key`，重复提交返回 `duplicated: true`。
3. **工具/能力治理框架**：Capability Center、Control Plane、工具目录、Agent 管理页面已上线，能力契约（适用域、风险等级、回退链）可见。
4. **SCP 外部工具集成真实可用**：浙江大学 SCP 服务连通，化学工具、文献检索工具可返回结构化结果。
5. **项目详情页修复**：`/projects` 点击项目行后，右侧可正确展示 基本信息 / 项目任务与交付要求 / 甘特图 / 实体图谱。

### [BEMCL-EQ-P0-001] 设备台账 - 新增设备保存失败

- 证据状态：[已实操验证]
- 优先级：P0
- 问题类型：功能/数据
- 证据编号：EV-20260728-004
- 位置：实验与样品 > 设备与校准 > 设备台账 > 新增设备弹窗
- 触发前提：admin 角色，已登录，页面 `/equipment`
- 复现步骤：
  1. 进入 `/equipment`。
  2. 点击“新增设备”。
  3. 填写名称并选择类别。
  4. 点击保存。
- 输入与对象：`EV-EQ-API-001`
- 预期表现：表单关闭，列表新增一行，提示保存成功。
- 实际表现：
  - 浏览器端：新增设备弹窗可打开，`/equipment` 页面导航无控制台错误，但 UI 保存未在实测中完成（自动化脚本因表单定位问题超时）。
  - 后端 API 实测：`POST /equipment` 返回 500，错误为 `ForeignKeyViolation: insert or update on table "equipment" violates foreign key constraint "fk_equipment_category"`。
  - 使用有效分类码 `equipment.preparation` 调用 API 可成功创建设备。
- 用户影响：普通用户无法通过 UI 新增设备，实验任务无法关联真实设备。
- 研发/合规影响：设备主数据缺失，实验可追溯性不满足 LIMS 要求。
- 根因假设：
  - 前端设备表单可能未正确绑定 `mdm.classifications` 中的有效分类码，或提交空/无效 category 值；
  - 也可能前端类别下拉使用了 `label` 而非 `code`。
- 整改方案：
  - 在 `EquipmentLedger.vue` 中确保类别选择器使用 `/mdm/classifications?domain=equipment` 的 `code` 字段提交；
  - 后端 `/equipment` 对无效 category 返回 400 中文提示，而非 500。
- 前端修改点：`frontend/src/views/EquipmentLedger.vue` 及相关表单组件。
- 后端/数据修改点：`battery_materials_agent/api.py` 中 `/equipment` 创建校验。
- 验收标准：在 UI 中填写必填字段并选择类别后点击保存，设备成功入库并在列表显示。
- 回归范围：设备台账、实验任务设备选择、设备详情。
- 建议责任角色：前端 + 后端
- 预计工作量：M
- 依赖、风险与数据迁移：无

- 项目新建页：当前三阶段目标输入→AI 拆解→确认，已具备向导，但“主表单按钮禁用”问题需修复，并增加禁用原因 tooltip。

- ECML 页面：在缺少实验数据时，首屏应直接提示前置条件，而非允许启动后超时。

### 8.4 空态、加载、失败、无权限、异步任务状态

- 空态：必须包含“为什么为空”+“下一步操作按钮”。

### 8.5 状态色、按钮层级、表格/筛选/批量/详情/版本对比规范

- 状态色：沿用 Ant Design 语义色（绿/蓝/橙/红），统一“待审核/待复核/草稿/已拒绝”等状态色。

- 版本对比：在配方/工艺/物料详情中增加“对比上一版本”入口。
