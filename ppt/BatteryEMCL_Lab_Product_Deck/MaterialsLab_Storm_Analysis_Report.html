1. 执行摘要

核心结论：MaterialsLab 是一套架构完整、对标 Deep Principle 的 AI 驱动电池材料研发闭环系统。其核心技术自研能力集中在 PEML（预测·评估·机器学习）八步调度引擎 和 工业化可行性筛选层，形成与头部 AI4S 公司的差异化错位。当前处于内部 PoC 向受控试点过渡阶段，存在 3 个 P0 阻断性问题待修复。

4. 核心发现

4.1 产品定位与技术架构

结论：MaterialsLab 定位为一整套开源版"Deep Principle"，以 OpenScience Agent 架构为底座，通过封装整合开源模型/工具构建电池材料研发闭环。

事实

4.1.1 架构九层设计

层级核心模块自研/集成评价
统一研发入口HybridOrchestrator + IntentInterpreter自研合理
RouterMaterialRouter（PSMILES > CIF/Formula > SMILES > Name）自研合理
材料流水线高分子分支（PSMILES + PolymerGNN）/ 晶体分支（pymatgen + CGCNN/M3GNet）集成开源合理
工业化验证合规检查 + 成本估算 + 配方设计 + RawMaterialDB自研差异化亮点
实验全链路任务单→审批→样品→数据录入→QC自研合理
PEML 调度八步闭环状态机自研核心壁垒
治理决策Committee + Release Card + Capability自研合理
数据治理MDM + Data Ingest + Knowledge自研合理
Agent 工具ActivityMapping + SKILL + SCP自研合理

关键发现：系统自研部分精准收敛于"编排逻辑 + 工业化 + 实验链路 + 治理层"，其余能力均采用开源方案整合。这一策略与 Deep Principle 的"全栈自研"形成差异化——我们更强调"集成世界顶级开源 + 强化决策最后一公里"。

4.1.2 PEML 八步引擎（核心自研）

步骤名称输入输出
01设计用户意图、目标候选生成计划
02预测候选结构性质 + 置信度
03合成目标分子合成路径 + 反应条件
04验证DFT 计算能量/能带
05实验筛选后候选实验任务 + 样品
06分析湿数据 + QC归一化结果
07学习预测-实测偏差模型校准信号
08决策委员会评审放行卡 + 下一轮迭代

4.2 产品成熟度与关键阻断

P0 阻断（3 项）：

  • BEMCL-MAT-P0-001：物料规格库列表因 toFixed 调用 undefined 崩溃 → 配方/BOM/成本核算原料选择断裂
  • BEMCL-EQ-P0-001：设备台账新增设备无法完成 → 实验任务无法关联设备
  • BEMCL-INGEST-P0-001：数据接入 CSV 导入无法完成 → 湿实验数据无法批量进入

P1 缺陷（3 项）：

  • BEMCL-UI-P1-001：DisabledButton 组件 null key 错误跨页面复现
  • BEMCL-PEML-P1-001：PEML 运行 API 超时（>3 分钟）
  • BEMCL-AI-P1-001：AI 候选生成化学式不规范（La3O、Li2O3 等）

4.3 差异化竞争壁垒

结论：MaterialsLab 的核心差异化在于"工业化最后一公里"——在 AI 预测之后增加合规检查、成本估算、供应链匹配、配方设计四层筛选，这是头部 AI4S 公司（Deep Principle、CuspAI、深势科技）不做或做得不好的能力。

推断

4.3.1 工业化筛选四级机制

层级能力实现
PASS合规检查通过SMARTS 毒性规则 + REACH 受限物质 + EHS 档案
PASS_WITH_RISKS有条件通过触发风险提示 + 人工复核
REVIEW需要评审进入 Committee 委员会评审
BLOCK直接拦截毒性超标/REACH 受限/供应链不可得

7. 风险与未知项

高风险：

  • 生产就绪度不足：3 个 P0 缺陷导致系统无法供真实团队日常使用
  • PEML 超时：运行 API >3 分钟，实验闭环迭代无法收敛
  • AI 输出质量：候选生成产出无效化学式（La3O、Li2O3），下游预测可能基于无效输入

中等风险：

  • DFT 能力缺失：无 VASP/PySCF 远程计算节点，精密验证仅灰化展示
  • 团队规模推断：代码库单人主导特征明显（无多人协作提交记录）
  • 商业化路径不明：当前未观察到定价页面、订阅模式或客户付费流程
  • 品牌认知：原名 BatteryEMCL Lab 已对外使用，更名为 MaterialsLab 需重建认知

未知项：

  • 与 Deep Principle 的真实技术差距（对方未开源，难以逐模块对比）
  • 客户付费意愿的量化数据（无 POC 签约数据）
  • 规模化部署的工程瓶颈（当前仅本地开发环境验证）
