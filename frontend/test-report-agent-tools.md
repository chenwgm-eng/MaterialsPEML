## 测试过程中发现并已修复的问题

| 严重级别 | 功能模块 | 问题描述 | 修复方式 |
| --- | --- | --- | --- |
| 严重 | 前后端路由冲突 | 直接访问 `/agents` 被后端 API 截获，返回 JSON 而非 SPA 页面，导致刷新/书签/外链无法进入该页面 | 在 `battery_materials_agent/api.py` 新增 `spa_html_routes_middleware`：对浏览器 GET 请求且 `Accept: text/html` 的非 API/静态资源路径优先返回 `index.html`，保留 API 的 JSON 响应给 `Accept: application/json` |
| 严重 | 前后端路由冲突 | 直接访问 `/tools` 被后端 API 截获，返回 JSON 而非 SPA 页面，导致刷新/书签/外链无法进入该页面 | 同上 |
| 高 | 登记能力抽屉保存按钮 | 测试脚本误判：Ant Design Vue 按钮文本被渲染为「保 存」（中间含空格），原脚本使用精确文本匹配导致报「保存按钮不可见」 | 更新 `frontend/test-agent-tools-capabilities.mjs`，使用正则 `/保\s*存/` 匹配按钮文本，并限定在「登记能力契约」抽屉内查找 |
| 中 | 新建智能体抽屉取消按钮 | 测试脚本存在同样误判风险：取消按钮文本为「取 消」 | 更新测试脚本，使用正则 `/取\s*消/` 匹配 |
